# 📊 Power BI Superstore Sales & Profit Analysis

Welcome to the **Power BI Superstore Sales & Profit Analysis** repository. This end-to-end business intelligence project transforms raw retail transaction data into actionable business insights. Using **Microsoft Power BI Desktop** and **Power Query Editor**, this interactive dashboard tracks overall revenue, isolates high-margin product categories, and maps regional sales distributions to empower data-driven decision-making.

---

## 🎯 Project Objectives
* **Performance Tracking:** Monitor total sales and net profit margins across multiple product dimensions.
* **Geographical Insights:** Identify high-performing and underperforming regions using spatial map visualizations.
* **Granular Product Analysis:** Breakdown revenue across main categories and sub-categories to uncover profit leaks.
* **Interactive Filtering:** Enable dynamic visual interaction and cross-filtering for strategic business evaluations.

---

## 🗄️ Dataset Details & Link
The project leverages the popular **Superstore Sales Dataset** available on Kaggle, which simulates transactional records for a global retail store.

* **Source Platform:** Kaggle
* **Dataset Link:** [Superstore Sales Dataset on Kaggle](https://www.kaggle.com/datasets/rohitsahoo/sales-forecasting)
* **Key Attributes:** `Order ID`, `Order Date`, `Ship Mode`, `Category`, `Sub-Category`, `Region`, `Sales`, `Profit`, `Quantity`, `Discount`.

## ⚙️ Data Cleaning & ETL Steps (Power Query)
Prior to data modeling, the raw dataset underwent key transformation steps inside Power Query Editor:
1. **Header Promotion:** Standardized table headers for consistent column referencing.
2. **Data Type Casting:** Standardized numerical columns (`Sales`, `Profit`) to decimal values and dates to standard datetime formats.
3. **Attribute Renaming:** Cleaned up column naming conventions (e.g., reformatting `Sub-Category` to `Sub Category` for clean display).
4. **Data Validation:** Audited null records, standardizing blank cells, and checking data integrity across 8+ sequential steps.

---

## 📈 Dashboard Layout & Visual Components

The report canvas is organized logically to ensure smooth visual scannability:

* 💳 **Profit Summary KPI Card:** Displays overall financial health and total profit margin at a single glance.
* 📊 **Category-wise Sales Bar Chart:** Comparative visual breakdown of revenue generated by main departments (*Furniture, Office Supplies, Technology*).
* 📉 **Sub Category-wise Sales Bar Chart:** Deep-dive visual tracking individual product lines (*Chairs, Storage, Phones, Labels, etc.*).
* 🗺️ **Region-wise Sales Map:** Spatial map component utilizing proportional bubbles to show market penetration across global/national sales regions.
